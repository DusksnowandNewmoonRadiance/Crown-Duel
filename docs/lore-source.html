一、防火墙时间点 已解决

结论：防火墙是在核弹例行复仇期间建立的，用于应对核弹。

时间线：凹槽被赶出 → 核弹开始例行复仇 → 克里斯蒂安松建立防火墙 → 核弹仍钻空子来过几次 → 猪瘟鱼事件后核弹彻底停止 → 当前

防火墙是应对措施，不是事前防御。核弹在防火墙建立后仍短暂袭击过几次，但风险越来越高，最终放弃。

二、断供机制 vs 凹槽建国 已解决

结论：凹槽在被赶出旧大陆之前，就已经和架子班一起开发出了复制皇冠。

时间线：凹槽还是卡兹帝国组织时 → 和架子班合作制造复制皇冠和催产工具 → 被赶出旧大陆，皇冠断供 → 但已有复制皇冠，卡牌来源没断 → 建立新大陆 → 架子班后续制造解析工具和更改工具

断供机制对付的是“没有替代方案就分裂”的势力。小白军区没有复制皇冠，断供即死。凹槽有复制皇冠，断供弄不死他们。

三、梯队口径 已解决

结论：梯队按国家整体实力计算，不按头目个人实力计算。

小怪兽国是第三梯队国家，但绘梨衣个人是架子班成员，个人实力属于顶尖梯队。普鲁士国是第四梯队国家，但045个人是架子班成员，个人实力属于中坚以上。架子班是超国家集团，成员个人实力与国家梯队无关。

声明：国家梯队看国家，人物梯队看个人。两者不混用。架子班第一梯队成员（七星、苏苏）个人实力按“顶尖”标注，与其所属国家的国家梯队无关。

五、苏苏设定加强 已补全

身份：架子班最主要成员（第一梯队，与七星相仿）、彗星高层、鸭子系领袖。已退出军事一线，只保留政治/象征地位，仍接受挑战。

1. 苏一世——旧大陆贫困地区出身，常年保持1段。偷渡新大陆后辅佐045建立普鲁士，被逐后入肉铺子国学习卡牌技术，受小岛抹黑彗星宣传影响，猛烈进攻彗星，被七星亲自镇压，作恶多端死亡。

2. 苏二世——自行引渡至德德，逐渐正常化，与爻等交好。游历彗星，发现小岛宣传为假，与七星建立友好关系并加入架子班。后被极端仇新大陆人士刺杀死亡。

3. 苏三世——引渡至刚制作的身体暮雪，人脉威望达到顶峰，正式成为彗星高层，同时在定于、贝壳、普鲁士、彗星、鸭子、逆流及许多零散小邦国中担任高层。

灵魂引渡：苏苏自行掌握灵魂引渡能力，三世为同一灵魂，记忆连续。灵魂引渡需提前准备身体，未准备则只能仓促寻找（如叶戈尔附身熊猫）。在新大陆上层，灵魂引渡几乎是标配。

实力加强点：
