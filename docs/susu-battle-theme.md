# 苏苏 · 战斗曲《赤色铁流》

> 曲子：`public/audio/bgm/susu.ogg`（1:55，D 小调 → E 小调，120 BPM）
> 乐谱：`tools/music/susu_theme.py`（导出 `tools/music/susu.mid`）
> 音源：fluidsynth 2.6 + MuseScore_General.sf3（真采样乐器；脚本里那套 numpy 合成是兜底）
> 接入：苏苏参战（自己用或对手用）时，`public/js/game-ui.js` 把 BGM 切到 `susu`

## 一、写法：照着苏联军旅歌的规矩

| 规矩 | 在这首里 |
| --- | --- |
| **和声小调**：小调 + 升七级，属和弦是大三和弦 | 全曲用 C#（`A7 = A–C#–E–G`）。第 11 小节、副歌第 30 小节那两句 `C# → D` 的解决，是「苏式」最明显的耳朵标记 |
| **四小节一句，句尾落属和弦再解决** | `i–i–iv–V ｜ i–VI–V–i` |
| **附点起句** | 每句头一个音都是「长–短」 |
| **同头变尾** | A 段第二遍（16–23）头两小节不动，后面抬高一句、加花 |
| **级进下行 + 一次大跳** | 主歌句内基本级进，句尾才跳四/五度 |
| 不用踩镲、不用失真 | 军乐队没那种声音 |

## 二、配器（全部是真采样）

钢琴 · 圆号（主歌旋律）· 手风琴（主歌加色 + 间奏独奏）· 小号（副歌旋律，高潮再加一条高八度）·
弦乐组 · 颤音弦乐（高潮段）· 合唱 · 拨弦低音 · 定音鼓 · 军鼓 · 底鼓。

副歌 `F – C – Dm – Bb ｜ F – C – A7 – Dm`；间奏 `Gm – Dm – Bb – A7 – Gm – Dm – A7 – A7`。

## 四、高潮是怎么做出来的

上一版「高潮不强」，是因为**只有音量在变**。这一版叠了六件事：

1. **升全音**：第 40 小节起整体 +2 个半音（D 小调 → E 小调）。同样的旋律、同样的配器，
   只因为高了大二度，耳朵立刻知道「到顶了」。这是最便宜也最有效的一招。
2. **小号高八度**：`lead2` 把副歌旋律再高八度叠一层，铜管的亮度直接翻倍。
3. **全员上**：副歌二从第一拍就是钢琴八度、弦乐双八度、铜管长音、合唱、定音鼓、军鼓、镲。
4. **滚奏顶**：44–47 小节定音鼓 32 分、军鼓 32 分同时滚，四小节不停。
5. **颤音弦乐**：44 小节起弦乐换成 tremolo patch，织体密度肉眼可见地上升。
6. **断—砸**：52–53 两小节滚奏 + 铜管长音把张力拉满，54 小节落地，55 小节余响。

动态上的证据（每四小节 RMS，dBFS）：

```
前奏 -43 → 主歌 -29 → 副歌 -23 → 间奏 -34 → 副歌二 -18 → 高潮 -15 → 尾奏 -17 → 收尾 -24
```

## 六、重跑

```bash
# 1. 出 MIDI（谱子在 susu_theme.py 里）
python -c "import sys;sys.path.insert(0,'tools/music');import susu_theme as T;T.build();T.write_midi('tools/music/susu.mid',T.EV)"

# 2. 用真音源渲染（需要 fluidsynth 2.6 + 任意 GM SoundFont，这里用 MuseScore_General.sf3）
fluidsynth -ni -F .tmp/susu_gm.wav -r 44100 -g 0.45 \
  -o synth.reverb.active=1 -o synth.reverb.room-size=0.88 -o synth.reverb.level=0.75 \
  -o synth.chorus.active=1 -o synth.polyphony=192 -o synth.gain=0.55 \
  MuseScore_General.sf3 tools/music/susu.mid

# 3. 母带（先量 I，再按差值做静态增益，最后限幅）
ffmpeg -i .tmp/susu_gm.wav -af ebur128=peak=true -f null NUL      # 读 I
ffmpeg -y -i .tmp/susu_gm.wav -af "volume=2.3dB,highpass=f=45,\
lowshelf=f=130:g=-3,equalizer=f=250:t=q:w=1.0:g=-1.5,\
equalizer=f=700:t=q:w=1.1:g=1.5,equalizer=f=2800:t=q:w=1.2:g=-2,\
equalizer=f=1200:t=q:w=1.4:g=1,highshelf=f=6000:g=0.5,\
alimiter=limit=0.8:attack=5:release=80:level=disabled,afade=t=out:st=112:d=3" \
  -c:a libvorbis -q:a 4 public/audio/bgm/susu.ogg
```

改曲子：`VERSE_MEL` / `VERSE_MEL2` / `CHOR_MEL` / `BRK_MEL` 是旋律表，
格式 `(小节内第几拍, 拍数, 音名)`；`VERSE8` / `CHOR8` / `BRK8` 是和声进行；
升调在第 `build()` 末尾那五行；各声部的 GM 推子在同文件的 `MIX` 里。

## 七、技术备注

- **`alimiter` 的 `level` 必须关掉**：ffmpeg 默认会把限幅后的输出重新拉到 0 dB，等于没限。
- **不要用 `loudnorm`** 收尾：它会增益骑乘，把段落起伏压平（LRA 从 17 掉到 7）。
  正确做法是先量 I，再一次静态增益 + 限幅。
- GM 通道号：钢琴 0 / 手风琴 8 / 颤音弦乐 13 / 弦乐 2 / 铜管 4 / 圆号 5 / 小号 6 + 高八度 12 /
  合唱 3 / 拨弦低音 11 / 低音提琴 0 / 定音鼓 7 / 打击 9。
- 成品指标：`I ≈ -15 LUFS`、`TP -1.5 dBFS`、`LRA 16.7 LU`；
  频段 `<150 Hz 12.6% / 200 Hz–1.2 kHz 58.5% / 1–3 kHz 29.1% / 6 kHz 以上 0.6%`。
