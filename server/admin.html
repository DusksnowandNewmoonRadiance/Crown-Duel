数值平衡（热更新）

在这里修改卡牌的费用、攻击、生命、携带上限、名称或描述，保存后新开的对局立即生效（进行中的对局不受影响），无需重启。 格式：{"卡牌师:卡牌id": {"cost": 3, "atk": 4, "hp": 5, "limit": 2, "text": "..."}}。删掉某一条即可恢复原始数值。 可修改的字段：cost、atk、hp、limit、n（默认卡组张数）、name、text、flavor。
