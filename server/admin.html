维护 / 平滑更新

平滑更新：开启维护（不能开新对局），等进行中的对局打完后自动重启服务器加载新代码。部署脚本会自动调用这个功能，一般不需要手动点。

数值平衡（热更新）

在这里修改卡牌的费用、攻击、生命、携带上限、名称或描述，保存后新开的对局立即生效（进行中的对局不受影响），无需重启。 格式：{"卡牌师:卡牌id": {"cost": 3, "atk": 4, "hp": 5, "limit": 2, "text": "..."}}。删掉某一条即可恢复原始数值。 可修改的字段：cost、atk、hp、limit、n（默认卡组张数）、name、text、flavor、rarity（common / rare / special / elite，改稀有度会同步改携带上限）。

DIY 角色

玩家自制的卡牌师（与正常池分开，只在「允许 DIY」的房间可用）。删除会立即从服务器移除、落盘并广播给在线玩家； 内置角色删除后当前进程内不再可用，但服务器重启会重新注册。
