# 皇冠对决 · 网页联机版

10 位卡牌师的快节奏卡牌对战。支持**单人练习（3 档电脑难度）**、**联机大厅**（快速匹配、创建房间、房间密码、邀请链接、大厅/房间聊天、断线重连）和**完整的卡组页面**。

## 目录结构

```
crown-duel/
├─ server/index.js      联机服务器（Express + Socket.IO，大厅 / 房间 / 匹配 / 计时 / 断线重连 / 维护）
├─ server/admin.*       运营后台（公告、广播、维护、数值热更新）
├─ server/store.js      运营数据存储（公告、数值，保存为 JSON）
├─ docs/                设定集存档与设定数据说明
├─ shared/              浏览器与服务器共用的代码
│  ├─ lore.js           设定数据（人物档案、世界观），图鉴与剧情模式共用
│  ├─ cards.js          全部卡牌数据、默认卡组、卡组校验
│  ├─ engine.js         规则引擎（联机时由服务器裁决，防作弊）
│  └─ ai.js             电脑对手
├─ public/              网页前端（无需构建）
├─ deploy/              部署脚本：setup.sh / systemd 服务 / nginx 配置
└─ test/                自动化测试（规则 / 卡组 / 对战模拟 / 联机 / 运营 / 聊天）+ 调参脚本
```

## 本地运行

需要 Node.js 18 或更高版本。

```bash
npm install
npm start
```

浏览器打开 http://localhost:3000 。同一局域网的朋友用 `http://你的电脑IP:3000` 即可联机。

测试：`npm test`（会跑 AI 互打模拟，以及两个机器人通过服务器打完一整局联机）。

## 部署到服务器

1. 把整个 `crown-duel` 目录上传到服务器（`node_modules` 不用传），例如：
   ```bash
   scp -r crown-duel 你的用户名@服务器IP:~/
   ```
2. 登录服务器，进入目录，执行一键部署（需要 sudo 权限）：
   ```bash
   cd ~/crown-duel
   sudo bash deploy/setup.sh
   ```
   - 有域名并想用 Nginx（推荐，走 80 端口）：`sudo DOMAIN=你的域名 bash deploy/setup.sh`
   - 想换端口：`sudo PORT=8080 bash deploy/setup.sh`
3. 脚本会自动：安装 Node 20（如果没有）→ 创建专用的无登录系统用户 `crownduel` → 复制程序到 `/opt/crown-duel` → 注册为开机自启的 systemd 服务。
4. 没用 Nginx 时，记得在云服务器的**安全组 / 防火墙**放行端口（默认 3000）。

常用命令：

```bash
sudo systemctl status crown-duel     # 查看状态
sudo journalctl -u crown-duel -f     # 实时日志
sudo systemctl restart crown-duel    # 重启
```

## DIY 角色（自制卡牌师）

玩家可以自己上传卡牌师，**和原版池完全分开**，官方不需要为它们调平衡：

- 建房时选「原版房间」或「允许 DIY」；DIY 角色只能在 DIY 房间使用，原版角色两边都能用，快速匹配只会匹配同池的人。
- 大厅进「DIY 工坊」：填角色信息 + 卡表 → 实时预览 → 上传；也可直接调 `POST /api/diy/heroes`。
- 角色只能用 26 项**既有机制**拼卡（抽牌 / 直伤 / 治疗 / 护甲 / 横扫 / 群体增益 / 嘲讽 / 冲锋…），不接受脚本，因此不会破坏服务器或引擎。
- 内置示例角色只有一个：**苍蓝**（30 血，抽牌续航 + 嘲讽 + 终焉直伤）。

完整字段表、机制目录、接口与限制见 [docs/diy-heroes.md](docs/diy-heroes.md)。

## 图鉴

主页点「图鉴」：人物档案（42 人，外貌 / 背景 / 卡组）、世界观原文、全部卡牌。设定数据来自作者的设定集（`shared/lore.js`），可使用的卡牌师会标注「可使用」，并能直接跳到卡组页。

## 稀有度与卡牌特效

卡牌分四种稀有度，稀有度决定携带上限：

| 稀有度 | 携带上限 | 特效 |
|---|---|---|
| 普通 | 4 张 | 无 |
| 稀有 | 3 张 | 无 |
| 特殊 | 2 张 | 一部分带通用特效，同类效果的卡共用 |
| 精英 | 1 张 | 每张都有自己的专属特效，互不重复 |

- 卡面边框和宝石按稀有度着色，精英卡有流光。
- 打出特殊 / 精英卡时会播放对应的出牌特效（精英卡还会显示卡名横幅）；图鉴里点开卡牌可以预览特效。
- 特效配方是数据（`shared/cardfx.js`），动画由 `public/js/cardfx.js` 播放。新增精英卡时在 `ELITE` 里加一条配方，`test/rarity.js` 会检查有没有遗漏或重复。
- 图鉴的卡牌页支持按**角色、花费、类型、稀有度**同时筛选。

## 卡组

主页点「编辑卡组」进入卡组页面：

- 每个玩家最多保存 **30 个**卡组（所有卡牌师加起来），每个卡组可以自己命名（16 字以内）。
- 卡组必须正好 40 张、且每张不超过携带上限才能**出战**；凑不满 40 张的卡组可以先保存，之后再补。
- 每个卡牌师有一套官方推荐卡组，不能直接修改；一修改就会自动变成你自己的新卡组。
- 「设为出战」决定单人练习和联机对战用哪个卡组。主页的「出战卡组」下拉框可以直接切换。
- 「导出代码」会复制一串 `CD1.…` 开头的卡组代码，可以发给朋友，或者自己备份；「导入代码」粘贴即可还原。
- 卡组保存在玩家自己浏览器的本地存储里。换浏览器、换设备或清除网站数据后卡组会丢失，建议用卡组代码备份重要的卡组。
- 管理员在后台调整了卡牌数值后，如果某个卡组因此超出了携带上限，会标记为「需调整」，调整好之前不能出战。

## 更新游戏（热更新）

在服务器上拉取最新代码，再执行一次部署脚本：

```bash
cd ~/Duel && git pull && sudo npm_config_registry=https://registry.npmmirror.com bash deploy/setup.sh
```

更新是**平滑**的，不会打断玩家：

1. 新版本先装到临时目录，装好后再切换，切换前旧版本照常运行。
2. 新的网页立即生效。在线玩家会收到「游戏已更新」提示，点一下就刷新到新版本；正在对局的玩家不会被打扰，对局结束后才提示。
3. 服务器进入维护模式：不能开新对局，进行中的对局正常打完后，服务器自动重启加载新代码（最多等 15 分钟，可用 `DRAIN_MINUTES=30` 调整）。
4. 重启只需一两秒，玩家的网页会自动重新连接。

## 运营后台

浏览器打开 `http://你的地址/admin`，输入后台口令。口令在部署时自动生成，查看方法：

```bash
sudo cat /etc/crown-duel.env
```

后台功能：

- **服务器状态**：在线人数、进行中对局、房间数、版本号。
- **公告**：分为公告、更新、活动、维护四类，可以置顶，也可以设为「登录时弹出」。发布后在线玩家立即收到提醒，未读公告有小红点。
- **全服广播**：立即在所有玩家屏幕顶部显示一条消息（包括正在对局的玩家）。
- **维护 / 平滑重启**：手动开关维护模式，或者等对局结束后重启。
- **数值热更新**：修改卡牌的费用、攻击、生命、携带上限、稀有度、名称、描述，保存后新开的对局立即生效，不用重启。删掉某一条覆盖就恢复原值。

公告和数值保存在 `/var/lib/crown-duel`，更新程序不会覆盖它们。

## 可调参数（环境变量）

| 变量 | 默认 | 说明 |
|---|---|---|
| `PORT` | 3000 | 监听端口 |
| `HOST` | 0.0.0.0 | 监听地址（配合 Nginx 时用 127.0.0.1） |
| `TURN_SECONDS` | 75 | 联机每回合时长（秒），超时自动结束回合 |
