# 皇冠对决 · Crown Duel

> 网页联机卡牌对战。10 位官方卡牌师 + **玩家自制（DIY）角色**，支持单人练习、联机大厅、房间对局与断线重连。
> 纯前端 + Node/Express + Socket.IO，无构建步骤，`npm start` 即跑。

**当前版本：3.3.1** · 适配桌面 / 平板 / 手机横竖屏

---

## 快速开始

需要 Node.js 18+。

```bash
npm install
npm start
```

浏览器打开 <http://localhost:3000>。同局域网的朋友用 `http://你的IP:3000` 即可联机。

```bash
npm test        # 14 个测试文件（规则 / 卡组 / 联机 / DIY / AI 流派 / 运营）
```

## 玩法一览

| 模式 | 说明 |
|---|---|
| 单人练习 | 三档电脑难度；可指定对手与敌方卡组（七星有两套预设） |
| 联机大厅 | 快速匹配、创建房间、房间密码、邀请链接、大厅与房间聊天 |
| 房间类型 | **原版房间**（默认）或 **允许 DIY** —— 两种池子严格分开 |
| 图鉴 | 42 人设定档案、世界观原文、全部卡牌，支持多维筛选 |
| 卡组 | 每位卡牌师一套官方推荐卡组，可自建最多 30 套，支持 `CD1.` 卡组码导入导出 |
| 剧情模式 | 八幡「渔村都烧了」第一章，含 AVG 开场与星评 |
| 商店 / 仓库 | 金币、剧情卡包、升级券 |
| 运营后台 | `/admin`：公告、广播、维护、平滑重启、数值热更新 |

## DIY 角色（本版重点）

玩家可以自己做卡牌师，**不用等官方调平衡**——代价是 DIY 角色与原版池完全分开：

- 建房时选「原版房间 / 允许 DIY」；DIY 角色只能进 DIY 房间，原版角色两边都能用；快速匹配不跨池。
- 主页 / 大厅进「DIY 工坊」：三栏编辑器（角色信息 / 卡表 / 实时卡面预览）+ 校验 + 导入导出 JSON + 说明书。
- 卡牌只能用 **31 项既有机制**拼装（抽牌 / 直伤 / 治疗 / 护甲 / 横扫 / 群体增益 / 嘲讽 / 冲锋 / 神罚体系…），不接受脚本，所以不会破坏服务器或引擎。
- 接口：`GET /api/diy/catalog`、`GET/POST /api/diy/heroes`、`GET/PUT/DELETE /api/diy/heroes/:name`。
- 内置示例只有一个：**苍蓝**（30 血 / 17 张卡，神罚体系 + 抽牌嘲讽 + 终焉直伤）。

完整字段表、机制目录与接口说明见 [docs/diy-heroes.md](docs/diy-heroes.md)。

## 部署

```bash
scp -r . 用户名@服务器:~/
cd ~/项目目录
sudo DOMAIN=你的域名 bash deploy/setup.sh     # 用 Nginx；不加 DOMAIN 则直接监听 3000
```

运营数据（公告 / 数值 / 账号 / **DIY 角色**）保存在 `DATA_DIR`，默认 `/var/lib/crown-duel`，升级程序不会覆盖——**备份这个目录就等于备份玩家数据**。

常用命令：

```bash
sudo systemctl status crown-duel
sudo journalctl -u crown-duel -f
sudo systemctl restart crown-duel
```

## 环境变量

| 变量 | 默认 | 说明 |
|---|---|---|
| `PORT` | 3000 | 监听端口 |
| `HOST` | 0.0.0.0 | 监听地址（Nginx 反代时用 127.0.0.1） |
| `DATA_DIR` | `./data` | 运营数据与 DIY 角色存档目录 |
| `TURN_SECONDS` | 75 | 联机每回合时长（秒） |
| `ADMIN_TOKEN` | 随机 | 后台口令（少于 12 位会每次启动随机生成） |
